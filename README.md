# Programación EVA 3

Aplicación Flask para resolver los dos ejercicios solicitados.

## Ejecución

1. Comprobamos la version de python

   ```text
   py --version
   ```

2. Instalar dependencias:

   ```text
   py -m pip install -r requirements.txt
   ```

3. Iniciar la aplicación:

   ```text
   python app.py
   ```

4. Abrir `http://127.0.0.1:5000` en el navegador.
